# RATIO PARK｜レイシオパーク

小学6年生算数「比とその利用」を、8つの短いゲームでくり返し学ぶWebアプリです。見て・判断して・すぐ確かめるテンポを大切にしています。

## 収録ゲーム

1. 同じ比タッチ
2. 比をちいさくせよ！
3. 比の値ハンター
4. 比の神経衰弱
5. ニセモノを探せ！
6. 穴あき比
7. どっちが大きい？
8. 比チェーン

すべて EASY / NORMAL / HARD の60秒チャレンジです。HARDでは小数を含む比を扱い、数字を大きくするだけではない深い判断を求めます。正解を続けるとコンボで得点が伸びます。

## 起動・公開

`index.html` をブラウザで開くだけで起動します。GitHub Pagesでは **Settings → Pages** から `main` ブランチの `/(root)` を公開元に設定してください。

## 保存データ

ブラウザの `localStorage` に、ゲーム・難易度別のBEST SCORE、プレイ回数、正解・誤答数、最高コンボ、問題タイプ別のチャレンジ記録を保存します。ホームの「記録をリセット」で消去できます。

## 技術構成

HTML / CSS / JavaScript（ES Modules）のみで動作します。正解・不正解などの短い効果音は、ブラウザ標準のWeb Audio APIで生成します。外部サーバー、データベース、外部API、APIキー、有料サービス、音源ファイル、外部フォントは使用していません。
