# RATIO PARK｜レイシオパーク

小学6年生算数「比とその利用」を、目で見て試すラボと8つの短いゲームで学ぶWeb教材です。比の意味・等しい比・比の値・比で分ける考え方を、身近な場面と繰り返しの練習でつなぎます。

## まずは「比ラボ」

トップ画面の「比ラボ」から、自分のペースで試せます。時間制限はありません。

- **比を体験**：原液と水の比を動かし、比が同じとき・変わるときを確かめる
- **同じ比**：両方に同じ数をかける、または割ると等しい比になることを試す
- **比の値**：「前の数 ÷ 後ろの数」を分数・小数で見比べる
- **生活ミッション**：飲み物、ビーズ、おかし作り、人数を比で分ける

## 8つのゲーム

1. 同じ比タッチ
2. 比をちいさくせよ！
3. 比の値ハンター
4. 比の神経衰弱
5. ニセモノを探せ！
6. 穴あき比
7. どっちが大きい？
8. 比チェーン

各ゲームには EASY / NORMAL / HARD の60秒チャレンジがあります。HARDでは小数を含む比も扱います。正解が続くとコンボで得点が伸び、問題中は考え方のヒントを開いて確かめられます。間違いも次の考えにつながるように、ナビキャラクターと短い解説で支えます。

## 学習の流れ

比ラボで関係を確かめる → ゲームでいろいろな形の問題に挑戦する → ヒントで考え方を振り返る → もう一度試す、という流れを想定しています。

## 起動・公開

HTML / CSS / JavaScript（ES Modules）の静的Webアプリです。GitHub Pagesで公開できます。npm、ビルド、データベース、外部API、APIキー、有料サービス、外部フォントは使用していません。キャラクター画像はTT-senseiのナビキャラクターWebP素材を参照しています。

## 保存データ

ブラウザの `localStorage` に、ゲーム・難易度別のBEST SCORE、プレイ回数、正解・誤答数、最高コンボ、問題タイプ別のチャレンジ記録を保存します。ホームの「記録をリセット」でRatio Parkの記録を消去できます。既存の `ratioPark.v1` と `ratioPark.badges.v1` の保存キーは維持しています。
