# RATIO PARK｜レイシオパーク

小学6年生算数「比とその利用」を、短いゲームをくり返しながら学ぶためのWebアプリです。説明を読むよりも、見て・判断して・すぐ結果を確かめる学びを大切にしています。

## 対象

小学6年生（比とその利用）／タブレット・PC

## 収録ゲーム（第1回）

1. 同じ比タッチ：等しい比を見つける
2. 比をちいさくせよ！：同じ数で割り、比を簡単にする
3. 比の値ハンター：比の値を既約分数で答える
4. 比の神経衰弱：等しい比のペアを集める

すべて EASY / NORMAL / HARD の60秒チャレンジです。HARDでは小数を含む比を扱います。

## 起動方法

`index.html` をブラウザで開くだけで起動します。ビルドやインストールは不要です。

## GitHub Pages

GitHub の **Settings → Pages** で、`Deploy from a branch`、ブランチ `main`、フォルダ `/(root)` を選んで保存します。

## 保存する内容

ブラウザの `localStorage` に、ゲーム・難易度別ベストスコア、プレイ回数、総正解・誤答数、最高コンボ、将来のにがて練習用の誤答タイプを保存します。ブラウザのデータを消すか、ホームの「記録をリセット」で初期化できます。

## 技術方針

HTML / CSS / JavaScript（ES Modules）のみで動作します。外部サーバー、データベース、外部API、APIキー、有料サービス、外部フォントは使用していません。
